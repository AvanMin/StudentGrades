# Личный кабинет успеваемости студента (`StudentGrades`)

Мобильное Android-приложение на языке Kotlin для учёта учебных оценок, многокритериальной фильтрации и сортировки, расчёта среднего балла, анализа динамики успеваемости и прогнозирования целевого результата.

## Основные экраны приложения
1. **Главная (`HomeFragment`)** — общий средний балл, количество оценок и дисциплин, быстрая сортировка карточек предметов (по дате, по баллу или выбор одной дисциплины) и переход к фильтрам.
2. **Фильтры (`FilterFragment`)** — расширенная фильтрация оценок по дисциплине, типу учебной работы («Контрольная», «Ответ», «Практическая», «Лабораторная»), периоду дат («С» / «По») и выбор режима сортировки.
3. **Оценки дисциплины (`DisciplineGradesFragment`)** — журнал оценок по выбранному предмету (значение, дата, тип работы, комментарий), локальная фильтрация/сортировка, редактирование и удаление записей.
4. **Добавление / редактирование оценки (`AddEditGradeFragment`)** — форма ввода и изменения записи с проверкой диапазона `2–5`.
5. **Динамика (`DynamicsFragment`)** — изменение среднего балла по месяцам и расчёт тренда успеваемости.
6. **Калькулятор цели (`GoalFragment`)** — расчёт минимальной оценки за следующую работу для достижения желаемого среднего балла и проверка достижимости цели.

## Технологический стек
- **Язык:** Kotlin
- **Архитектура и UI:** Single-Activity, Fragments, ViewBinding, Material Components, Navigation Component (`nav_graph.xml`)
- **База данных:** Room (`AppDatabase`, `DisciplineDao`, `GradeDao`)
- **Асинхронность:** Kotlin Coroutines, `Flow` / `StateFlow`
