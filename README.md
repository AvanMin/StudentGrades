# Личный кабинет успеваемости студента (`StudentGrades`)

Мобильное Android-приложение на языке Kotlin для учёта учебных оценок, группировки их по дисциплинам, расчёта среднего балла и анализа динамики успеваемости.

## Основные экраны приложения
1. **Главная (`HomeFragment`)** — общий средний балл, количество оценок и краткая сводка по дисциплинам.
2. **Дисциплины (`DisciplinesFragment`)** — список предметов с указанием преподавателя и среднего балла.
3. **Оценки дисциплины (`DisciplineGradesFragment`)** — журнал оценок по предмету (значение, дата, тип работы, комментарий), фильтрация и сортировка.
4. **Добавление / редактирование оценки (`AddEditGradeFragment`)** — форма ввода и изменения записи с проверкой диапазона `2–5`.
5. **Динамика и калькулятор (`DynamicsFragment`)** — изменение среднего балла по периодам и расчёт требуемой следующей оценки для достижения целевого среднего балла.

## Правила оценивания (базовая версия)
- Допустимый диапазон оценок: от `2` до `5`.
- Средний балл рассчитывается как среднее арифметическое по всем внесённым записям (все оценки имеют одинаковый вес).
- При отсутствии оценок отображается понятная заглушка без деления на ноль.

## Запуск проекта
1. Клонировать репозиторий и открыть проект в Android Studio.
2. Дождаться завершения синхронизации Gradle (`Sync Project with Gradle Files`).
3. Запустить приложение (`Run 'app'`) на эмуляторе или Android-устройстве.
