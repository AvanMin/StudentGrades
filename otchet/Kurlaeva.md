# Отчёт о выполнении Спринта 2 (Lead Developer)

**Проект:** «Личный кабинет успеваемости студента» (`StudentGrades`)  
**Роль:** Lead Developer (Алина Курлаева)  
**Цель спринта:** Разработка моделей данных приложения, определение связей между сущностями дисциплин и оценок, подготовка основы для локального хранения данных.

---

## 1. Выполненные задачи

1. **Проектирование структуры данных приложения:**
    * Изучена структура хранения информации, необходимой для работы приложения.
    * Определены две основные сущности: `Discipline` и `Grade`.
    * Предусмотрена связь между дисциплинами и оценками по принципу «одна дисциплина — много оценок» (1:N).

2. **Разработка модели дисциплины (`Discipline.kt`):**
    * Создан Kotlin-класс `Discipline` в пакете `data/model`.
    * Добавлены поля `id` (идентификатор), `name` (название дисциплины) и `teacherName` (имя преподавателя).
    * Для идентификатора предусмотрено значение по умолчанию, а имя преподавателя сделано необязательным.

3. **Разработка модели оценки (`Grade.kt`):**
    * Создан Kotlin-класс `Grade` в пакете `data/model`.
    * Добавлены поля `id`, `disciplineId`, `value`, `date`, `workType` и `comment`.
    * Предусмотрена возможность связывать каждую оценку с соответствующей дисциплиной через `disciplineId`.
    * Комментарий сделан необязательным.

4. **Организация структуры данных проекта:**
    * Модели данных размещены в отдельном пакете `data/model`.
    * Сохранено разделение моделей данных и пользовательского интерфейса на отдельные пакеты.
    * Подготовлена основа для дальнейшего подключения локальной базы данных и реализации операций с записями.

5. **Проверка соответствия моделей требованиям проекта:**
    * Сверены названия и назначение полей моделей с требованиями технического задания.
    * Проверена возможность хранения нескольких оценок для одной дисциплины.
    * Учтены требования к хранению даты, типа учебной работы и комментария к оценке.
