**Продолжительность проекта:** 36 учебных часов (6 дней по 6 часов).

### 1. Цель проекта

Целью проекта является разработка мобильного приложения «Личный кабинет успеваемости студента», которое позволяет просматривать оценки, группировать их по дисциплинам, рассчитывать средний балл и отслеживать динамику успеваемости.

Приложение разрабатывается на платформе Android с использованием языка программирования Kotlin и локальной базы данных Room/SQLite.

### 2. Основные задачи проекта

В процессе разработки команда должна:
1. Проанализировать требования и определить пользовательские сценарии.
2. Спроектировать интерфейс и структуру приложения.
3. Создать модель данных для дисциплин и оценок.
4. Реализовать добавление, редактирование и удаление оценок.
5. Реализовать расчёт среднего балла.
6. Добавить фильтрацию и сортировку оценок.
7. Реализовать отображение динамики успеваемости.
8. Провести тестирование приложения.
9. Подготовить финальную сборку и демонстрацию проекта.

### 3. Распределение ролей в команде

В проекте используются три основные роли:

**Product Owner (PO) — владелец продукта**

- Разрабатывает функциональность приложения.

**QA / DevOps — тестировщик**

### 7. Основная структура базы данных

В приложении предусмотрены две основные сущности.

**Discipline:**
- id — идентификатор дисциплины;
- name — название дисциплины;
- teacherName — имя преподавателя (необязательно).

**Grade:**
- id — идентификатор оценки;
- disciplineId — идентификатор дисциплины;
- value — значение оценки;
- date — дата получения оценки;
- workType — тип учебной работы;
- comment — комментарий.

Связь между сущностями: одна дисциплина может иметь несколько оценок (1:N).

### 8. Логика расчёта среднего балла

Средний балл рассчитывается по формуле:

Средний балл = сумма всех оценок / количество оценок.

Например, если студент получил оценки 5, 4, 3 и 5, средний балл составит:

(5 + 4 + 3 + 5) / 4 = 4,25.

Все оценки в базовой версии имеют одинаковый вес. При отсутствии оценок приложение должно показывать понятное сообщение и не выполнять деление на ноль.
